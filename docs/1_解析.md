1.解析yaml

到时候是解析一个yaml文件夹下所有的文件!

yaml文件类似于:
```aiignore
filename: user
package: system

CreateThreshold:
  method: POST
  path: /thresholds
  filename: threshold
  req:
    name: string
    score: string
  res:
    id: int64
UpdateThreshold:
  method: PUT
  path: /thresholds/:id(int64)
  req:
    name: string
  res:
    updated: bool
GetCharacterSkills:
  method: GET
  path: /characters/:id(int64)/skills
  res:
    list:
      - id: int64
        name: string
        level: [int]
```
解析里面的文件生成对应的结构体

支持put,patch,post,get,delete请求,需要做好类型校验
做好method,path,filename,req,res的字段校验(有时候可以没有req或res)
method只能是post,put,patch,delete,get,不区分大小写
path:/开头等等
filename:单词开头不能大写,只能是一个单词,我这小驼峰命名
req,res中字段只能是go类型:

string,int,int64等等,float...,[]string,[]int,[]int64等等,等大部分go类型,以及一些嵌套类型,
不过[]int,在yaml中应该写出[int]
